The **Summer 6ix Pack Player** is a custom, browser-based music player designed exclusively for the *Summer 6ix Pack* album. Built with a frosted-glass glassmorphism interface, it gives you full playback control — play, pause, skip, and scrub through six original tracks without installing a single app or creating an account. Just open the page and press play.

## What's in These Docs

These docs walk you through everything you need to get the most out of the Summer 6ix Pack Player. **Using the Player** covers the day-to-day controls and playback features. **Customization** explains how to adapt the player's appearance and tracklist to your own needs. **Deployment** guides you through hosting the player so your audience can access it anywhere.

The player also exposes a small public JavaScript API for builders who want to extend or automate playback. The core functions are `loadTrack(index)` to programmatically load any track by its position in the playlist, `playAudio()` to start playback, and `pauseAudio()` to pause it. Track items in the HTML carry a `data-src` attribute on each `.track-item` element that holds the audio file path for that track. For progress tracking, the player's `<audio>` element fires the standard `timeupdate` event as playback progresses and the `loadedmetadata` event once a track's duration is known — both are used internally to drive the progress bar and are available for your own listeners.
